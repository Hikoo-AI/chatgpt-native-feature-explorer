# Changelog

## 0.3.0 — Initial public source release

- Native Business Hub manager, Insights metrics and Discovery Topics preview.
- Original Products tabs and local-only business-information drafts.
- English Hikoo UI with a permanent sample-data banner.
- Automatic Ads Manager / Shopify launch and runtime checks, with optional
  per-site permission and temporary background launch state.
- Memory Summary removed from the normal UI; research test retained.
- Curated source distribution, MIT license, local publication checks and an
  inactive CI template (activation requires GitHub workflow permission).

The full Agent builder and isolated Ads previews are not validated. The latest
complete Business Hub Orca test remains limited by a transport timeout. The
recorded demo documents a manual native preview, not every success criterion.
